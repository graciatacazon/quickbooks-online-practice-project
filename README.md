# QuickBooks Online Practice Project

## Project Overview

This project demonstrates my developing QuickBooks Online bookkeeping skills through a simulated small-business accounting workflow using a fictional U.S. residential cleaning business, Cedar & Sage Home Services LLC.

The project focuses on organizing financial transactions, maintaining accurate accounting records, reconciling bank activity, and reviewing financial reports.

**Project type:** Self-directed practice project  
**Accounting software:** QuickBooks Online  
**Business type:** Residential cleaning services  
**Reporting period:** January 2026  
**Data:** Fictional practice data

## Project Objectives

- Practice navigating QuickBooks Online.
- Organize and categorize business transactions.
- Review recorded transactions for accuracy and completeness.
- Reconcile the accounting records against bank activity.
- Generate and review financial statements.

## Skills Demonstrated

- Company setup and chart of accounts
- Transaction categorization and recording
- Bank reconciliation
- Profit and Loss reporting
- Balance Sheet reporting
- Financial record review and discrepancy identification

## Project Deliverables

The repository contains selected screenshots, supporting workpapers, and financial reports from the practice exercise.

- Company setup documentation
- Transaction records
- Bank reconciliation documentation
- Financial statements
- Project observations and review notes

## Learning Outcomes

This project helps me develop practical familiarity with QuickBooks Online workflows and apply my existing bookkeeping and accounting knowledge in a cloud-based accounting environment.

## Disclaimer

This is an independent learning project using fictional business information. It is not a client engagement and does not represent professional bookkeeping services performed for a U.S. business.
